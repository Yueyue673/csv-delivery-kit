CSV delivery kit / CSV 整理交付样例

把多份导出，整理成一份主表；需要确认的内容，单独列清楚。
你拿到的不只是一张表，还有问题来源和下次能继续运行的脚本。

演示效果：两份文件、9条输入，得到5条整理结果、3条待确认记录、1条完全重复记录。
比如编号00003分别出现8.00和9.00：两个版本都保留在待确认表中，附原文件与行号。
打开 demo/delivery/preview.html，可以切换三类记录、切换中英文、下载完整结果。
样例中的姓名、编号和金额均为合成数据，不是客户项目或客户资料。

更完整的验收：运行 python verify_batch.py。
它会生成三份共5000行的原创合成CSV，调用真正的命令行程序两次。
逐项核对完整字段、异常原因、原文件物理行号、输入校验值与重跑一致性。
本次实际结果：3850行整理结果、600行重复、550行异常（150个冲突编号、250行缺编号）。
两次运行的五份交付文件逐字节一致，记录在 validation/batch-check.json。
需要保留生成的输入和输出时：python verify_batch.py --output batch-evidence
输出目录必须是新目录，不覆盖旧文件。

能交付什么
- 合并列名相同但列顺序不同的 CSV；识别逗号、分号、制表符或竖线。
- 仅在明确选择时，去掉字段首尾空格、移除整行完全重复数据。
- 指定编号列后，同编号但内容不同的所有记录都进入异常表，等待客户确认。
- 保持字段文本原样，包括编号前导零、金额小数位和中文。
- 交付整理结果、异常与重复记录清单、计数报告和 HTML 预览。
- 全程本机处理；运行时不联网、不调用 AI、不读取账户凭证。

使用方法（Python 3.10 或更新版本，无需第三方包）
python csv_delivery.py first.csv second.csv --output new-delivery --key order_id --trim --dedupe-exact

运行时请把 preview_template.html 与 csv_delivery.py 放在同一文件夹。生成的报告可独立打开。

输入为 GB18030 编码时，添加 --encoding gb18030。
默认最多处理 100000 条非空记录；可用 --max-rows 调整。
输出目录必须是尚不存在的新目录，程序不会覆盖已有目录。
写入中断时，只尝试清理本次创建的文件；无关文件会保留，清理未完成会明确报错。
请先取得资料所有者授权，并在约定范围内处理文件。

Excel 查看注意
CSV 自身没有列类型。保存的编号文本保留前导零，但 Excel 直接打开时可能自动改为数字。
请通过“数据 -> 从文本/CSV”导入，将编号列设为文本；本样例不声称改变 Excel 的自动推断。
导入客户数据时也应使用文本列类型，避免软件自行执行或转换单元格内容。

边界
不猜测客户意图，不自动选择冲突数据的赢家，不证明源数据业务上正确。
列名不一致时先确认映射，不擅自改名或合并不同含义的字段。
当前只处理 CSV，不包含 PDF/OCR、网页抓取、Excel 公式、登录或支付操作。
程序没有收款功能。交付完成不等于成交或到账。
