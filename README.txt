CSV 整理交付

把几份导出整理成一份主表。完全重复的行、需要确认的记录，都会单独列出，并标上来源文件和行号。你还会拿到以后能再跑的脚本。

小例子：两份文件、9 条输入，得到 5 条整理结果、3 条待确认、1 条完全重复。
比如编号 00003 分别出现 8.00 和 9.00：两个版本都留在待确认表里，并附上原文件和行号。
打开 demo/delivery/preview.html，可以切换三类记录、切换中英文、下载完整结果。
例子里的姓名、编号和金额是合成数据。

更完整的验收：运行 python verify_batch.py。
它会生成三份共 5000 行的合成 CSV，把真正的命令行程序跑两遍。
逐项核对完整字段、异常原因、原文件物理行号、输入校验值与重跑是否一致。
本次实际结果：3850 行整理结果、600 行重复、550 行待确认（150 个冲突编号、250 行缺编号）。
两次运行的五份结果文件逐字节一致，记录在 validation/batch-check.json。
需要留下生成的输入和输出时：python verify_batch.py --output batch-evidence
输出目录必须是新目录，不会覆盖旧文件。

按你的文件改一版，起步价是 25 美元：最多 3 份 CSV、共 5000 条记录、20 列，规则先约定好。
你会拿到结果文件、可再跑的脚本和说明，并在约定范围内改一次。先看脱敏或编造的例子，再确认范围和日期。
工具本身按 MIT 许可免费使用。付费部分是按约定规则改适、核对输入并整理交付。

程序本身没有收款功能。交付完成不等于成交或到账。

能做什么
- 合并列名相同但列顺序不同的 CSV；识别逗号、分号、制表符或竖线。
- 只有在你明确选择时，才会去掉字段首尾空格，或移除整行完全重复的数据。
- 指定编号列后，同一编号但内容不同的记录都进入待确认表，等你决定。
- 字段文本保持原样，包括编号前导零、金额小数位和中文。
- 交付整理结果、待确认与重复清单、计数报告和 HTML 预览。
- 全程本机处理；运行时不联网、不调用 AI、不读取账户凭证。

使用方法（Python 3.10 或更新版本，无需第三方包）
python csv_delivery.py first.csv second.csv --output new-delivery --key order_id --trim --dedupe-exact

运行时请把 preview_template.html 与 csv_delivery.py 放在同一文件夹。生成的报告可以单独打开。

输入为 GB18030 编码时，加上 --encoding gb18030。
默认最多处理 100000 条非空记录；可用 --max-rows 调整。
输出目录必须是还不存在的新目录，程序不会覆盖已有目录。
写入中断时，只尝试清理这次创建的文件；无关文件会留下，清理未完成会明确报错。
请先取得资料所有者授权，并在约定范围内处理文件。

用 Excel 查看
CSV 自身没有列类型。保存的编号文本保留前导零，但 Excel 直接打开时可能自动改成数字。
请通过“数据 -> 从文本/CSV”导入，将编号列设为文本。
导入时对不信任的字段也建议使用文本列，避免软件自行转换单元格内容。这个工具不会执行表格公式。

边界
不替你选择冲突数据里哪一条是对的，也不证明源数据在业务上正确。
列名不一致时先确认对应关系，不会擅自改名或合并不同含义的字段。
当前只处理 CSV，不包含 PDF/OCR、网页抓取、Excel 公式、登录或支付操作。
